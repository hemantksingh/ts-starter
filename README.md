# ts-starter

A TypeScript learning journey that grows into a reusable starter template.

This repo starts deliberately empty of code. It follows a phased, just-in-time approach — each tool and concept is introduced only when the learning path needs it, and each phase is gated by a demonstrable milestone. The full path, from JavaScript basics through TDD, React, Postgres, Docker, and deployment to GCP Cloud Run, is laid out in **[ROADMAP.md](ROADMAP.md)**.

## Who this is for

- Developers with a JavaScript background making the jump to TypeScript
- Less-experienced devs who want a guided path to a working local setup
- Anyone who wants to learn by building and testing (red–green–refactor), not by reading alone

## Current status

📍 **Pre-Phase 0** — roadmap defined, no code yet. See the progress tracker in [ROADMAP.md](ROADMAP.md).

As phases complete, this repo accumulates the real artifacts: the TypeScript source, test suites, tooling config, and eventually the polished starter template (Phase 4) that new developers can clone and run.

## How progress is tracked

- Each phase ends with an observable **milestone** (a passing test run, a working demo, a deployed URL)
- Milestones are tagged in git (`phase-1-done`, `phase-2-done`, …)
- A short "what I learned" note per phase lives in `notes/`
